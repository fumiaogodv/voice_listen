- N2S 项目，两个问题处理：

1. 启动崩溃 `RuntimeError: Directory '/app/data/audio_cache' does not exist`：根因是 main.py 里 `app.mount("/audio", StaticFiles(...))` 在模块导入时执行，而 Docker 挂载 `./data:/app/data` 覆盖了 Dockerfile 里 RUN mkdir 建的目录，host 端若无 audio_cache 子目录则崩溃。修复：main.py 挂载前加 `CACHE_DIR.mkdir(parents=True, exist_ok=True)` + `NOTES_DIR.mkdir(...)`，让程序自建目录，不依赖 Dockerfile/host 预建。
