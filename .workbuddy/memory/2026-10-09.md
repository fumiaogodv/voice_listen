# 2026-10-09

- N2S 项目，两个问题处理：

1. 启动崩溃 `RuntimeError: Directory '/app/data/audio_cache' does not exist`：根因是 main.py 里 `app.mount("/audio", StaticFiles(...))` 在模块导入时执行，而 Docker 挂载 `./data:/app/data` 覆盖了 Dockerfile 里 RUN mkdir 建的目录，host 端若无 audio_cache 子目录则崩溃。修复：main.py 挂载前加 `CACHE_DIR.mkdir(parents=True, exist_ok=True)` + `NOTES_DIR.mkdir(...)`，让程序自建目录，不依赖 Dockerfile/host 预建。

2. 左侧目录默认收起：重写 renderLibrary 为可折叠树形结构（按 category 用 `/` 拆层级），默认全部收起，点击分类头展开/收起（箭头 ▸/▾），当前播放文件所属顶层分类自动展开。新增 expandedCats 状态 + renderLevel 递归渲染。CSS 加 cat-arrow/cat-name 样式。
- 用户当前数据：25 文件，4 个一级分类（new_史纲、操作系统、毛中特、计算机网络），都是两层结构（分类/文件），无更深层级。
- 环境：本地服务用隔离 venv 启动（uvicorn），Windows 下 agent-browser 仍不可用（daemon SIGTERM），验证靠 curl + node --check。
