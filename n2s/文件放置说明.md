# 文件放哪里？—— 分类目录结构说明

> 你只需要做一件事：**把笔记文件（.md 或 .txt）按分类丢进 `data/notes/` 目录**，程序会自动扫描、转语音、按目录归类。想分几层分几层。

---

## 1. 目录位置

| 环境 | 笔记放在哪 |
|---|---|
| **本地开发** | `n2s/data/notes/` |
| **Docker 部署** | host 端的 `n2s/data/notes/`（会被挂载进容器，compose 已配好） |

> 一句话：**永远是 `n2s/data/notes/` 这个目录**，本地和 Docker 都是它。

---

## 2. 目录结构规则（支持任意层级）

程序会按**文件所在的文件夹路径**自动归类。文件夹想建几层就建几层，左侧列表会按层级显示。

### 推荐的分类结构（你的场景：分类 → 章 → 笔记）

```
data/notes/
├── 操作系统/                          ← 一级分类
│   ├── 第一章 进程管理/                ← 二级（章）
│   │   ├── 进程与线程.md
│   │   ├── 进程同步与互斥.md
│   │   └── 死锁.md
│   ├── 第二章 内存管理/                ← 二级（章）
│   │   ├── 分页与分段.md
│   │   └── 虚拟内存.md
│   └── 第三章 文件系统/
│       └── 文件目录结构.md
├── 计算机网络/                        ← 一级分类
│   ├── 第一章 物理层/
│   │   └── 数据通信基础.md
│   └── 第二章 数据链路层/
│       └── 差错控制.md
└── 政治/                              ← 一级分类
    └── 马原/
        └── 唯物辩证法.md
```

### 显示效果

左侧列表会按层级归类显示，例如：

```

  进程与线程      已听 60%
  进程同步与互斥   未开始
  死锁           已听完
操作系统/第二章 内存管理
  分页与分段      未开始
  虚拟内存       未开始
计算机网络/第一章 物理层
  数据通信基础    未开始
政治/马原
  唯物辩证法      未开始
```

## 3. 规则要点

| 规则 | 说明 |
|---|---|
| **文件夹名 = 分类名** | 一级目录是"操作系统"，二级是"第一章 进程管理" |
| **想分几层分几层** | 支持任意深度，程序按完整路径归类 |
| **支持的文件类型** | `.md`、`.txt`、`.markdown` |
| **文件名** | 建议用知识点主题命名，如 `进程与线程.md`（会显示在列表里，也用于音频文件名） |
| **只放笔记** | 其他文件类型会被忽略 |

---

## 4. 操作流程（就这么简单）

### 本地开发

1. 把笔记放进 `n2s/data/notes/操作系统/第一章 进程管理/进程与线程.md`
2. 程序每 30 秒自动扫描一次（或点右上角 ⟳ 手动刷新）
3. 等它转好（状态从"转换中"变成可播放），点开就听

### Docker 部署

1. 在 host 端（你的 N100 服务器）把笔记放进 `n2s/data/notes/...`
2. `docker compose up -d` 启动后自动扫描
3. 浏览器访问 `http://服务器IP:8000`

> Docker 下，容器里的 `/app/data/notes` 和 host 的 `./data/notes` 是同一个目录（挂载），所以你在 host 放文件，容器立刻能看到。

---

## 5. 自动生成的东西（不用你管）

程序会在 `data/` 下自动生成这些，**你不需要手动创建**：

```
data/
├── notes/          ← 你的笔记（唯一需要你关心的）
├── audio_cache/    ← 自动生成的 MP3 音频缓存（按笔记路径镜像）
└── n2s.db          ← SQLite 数据库（存播放进度）
```

> `audio_cache/` 里的 MP3 是按笔记路径镜像生成的，例如 `操作系统/第一章 进程管理/进程与线程.md` → `操作系统/第一章 进程管理/进程与线程.mp3`。

---

## 6. 迁移 / 备份

- **备份笔记**：只备份 `data/notes/` 即可，音频能重新生成
- **备份全部**（含进度）：备份整个 `data/` 目录
- **换服务器**：把 `data/` 整个拷过去，进度和缓存都在
