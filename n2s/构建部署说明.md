# 构建 & 部署说明（照做即可）

> 构建交给你，配置已全部写好并验证过逻辑。下面按顺序执行。

---

## 一、本地构建镜像（在你网络好的环境执行）

```bash
cd n2s
docker build -t n2s:latest .
```

**为什么之前会失败**：你的网络到 pypi 不稳定（下载 imageio-ffmpeg 的 29.5MB 静态二进制时反复断流，报 `Read timed out` / `hash 校验失败`）。这**不是代码问题**，换网络好的时段或环境重跑即可。Dockerfile 里已加了 `--timeout 120 --retries 5` 提高容错。

> 若你网络实在下不动 imageio-ffmpeg，可以把 `requirements.txt` 里的 `imageio-ffmpeg` 删掉，改在 Dockerfile 里用系统包管理器装 ffmpeg（需自行配置 apt 国内源）。但优先试上面的默认方案。

---

## 二、启动容器

```bash
docker compose up -d --build
```

启动后：

- 服务跑在 `http://你的服务器IP:8000`
- 笔记目录 = host 端的 `./data/notes/`（和容器内 `/app/data/notes` 是同一个，挂载）

---

## 三、把笔记放进去

```
n2s/data/notes/
├── 操作系统/
│   ├── 第一章 进程管理/
│   │   └── 进程与线程.md        ← 直接丢文件，程序自动扫描转换
│   └── 第二章 内存管理/
│       └── 内存管理.md
└── 政治/
    └── 马原/
        └── 唯物辩证法.md
```

**规则**：想分几层分几层，文件夹名就是分类名。详细见 `文件放置说明.md`。

---

## 四、笔记内容怎么写（序号规范）

每条知识点一行，行首「数字 + 英文点号」，编号从 1 连续：

```
1.进程是程序的一次执行过程，是系统进行资源分配和调度的基本单位

2.线程是进程内的一个执行单元，是CPU调度的基本单位
```

程序会读成「第一条。…… 第二条。……」。详细见 `笔记序号规范.md`。

---

## 五、反向代理 + 鉴权（公网必须做）

`Caddyfile` 已备好模板，替换域名和账号密码后：

```
n2s.你的域名.com {
    basicauth { 用户名 <bcrypt哈希> }
    reverse_proxy 127.0.0.1:8000
}
```

生成密码哈希：`caddy hash-password`。

---

## 六、验证清单

构建并启动后，逐项确认：

- [ ] `docker logs n2s` 无报错，uvicorn 正常启动
- [ ] 浏览器打开 `http://IP:8000`，左侧能看到「操作系统/第一章 进程管理」分类
- [ ] 点文件，状态从「转换中…」变可播放（首次需几十秒，容器内 edge-tts 要联网到微软）
- [ ] 能播放、倍速、拖进度条、自动连播
- [ ] 关掉重开，进度还在（断点续播）
